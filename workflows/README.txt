FrameForge uses the live ComfyUI HTTP API rather than a bundled workflow file.

Start ComfyUI Desktop and make its API available at:
    http://127.0.0.1:8188

Install ComfyUI_IPAdapter_plus and the required SD 1.5 / IP-Adapter / CLIP Vision models.
Then use FrameForge Setup -> Refresh model lists.

This directory is reserved for future exported/reference workflows that may be added to the project.
